2️⃣  WHAT YOU NEED

3️⃣  INSTALLATION STEPS
─────────────────────────────────────────────────────────────────────────────────

STEP 1: SSH into your server
─────────────────────────────────────────────────────────────────────────────────
ssh root@your-server-ip

STEP 2: Run the installer
─────────────────────────────────────────────────────────────────────────────────
bash <(curl -fsSL https://raw.githubusercontent.com/fitnesshubgym03-debug/zwscloud-ui-db/main/install-auto.sh)

STEP 3: Wait for installation
─────────────────────────────────────────────────────────────────────────────────
The installer will:
  • Check your OS and install dependencies
  • Clone the repository
  • Ask for configuration
  • Set up the database
  • Create your admin user
  • Build the application

Total time: 10-30 minutes (depending on internet speed)

STEP 4: Start the application
─────────────────────────────────────────────────────────────────────────────────
cd zwscloud-ui-db
./start.sh

Or manually:
pnpm start

6️⃣  TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────────

ERROR: "curl: command not found"
→ The installer will install curl automatically. If it fails:
  Ubuntu/Debian: sudo apt-get install curl
  CentOS/Fedora: sudo yum install curl

ERROR: "bash: line 1: sudo: command not found"
→ Run commands without sudo if you're already root

ERROR: "Permission denied"
→ Make sure you have write permissions in the directory
  chmod 755 /path/to/directory

ERROR: "Port 3000 already in use"
→ Use a different port:
  PORT=3001 pnpm start

ERROR: "Database connection failed"
→ Check database is running and credentials are correct
  PostgreSQL: psql -h localhost -U postgres
  MySQL: mysql -h localhost -u root -p

MORE HELP: See AUTOMATED_INSTALL.md for detailed troubleshooting

7️⃣  NEXT STEPS
─────────────────────────────────────────────────────────────────────────────────

1. Change Admin Password
   └─ Log in to admin dashboard and update password immediately

2. Configure Payment Webhooks (if using Razorpay)
   └─ Go to Razorpay Dashboard → Settings → Webhooks
   └─ Add: https://your-domain/api/payments/razorpay-webhook

3. Review Environment Configuration
   └─ Edit: .env.production.local
   └─ Update: payment gateway keys, domain, etc.

4. Set Up Domain (if not done during setup)
   └─ Update DNS records
   └─ Configure SSL certificate
   └─ Set up reverse proxy (nginx/Apache)

5. Create Database Backups
   └─ PostgreSQL: pg_dump -U postgres zwscloud > backup.sql
   └─ MySQL: mysqldump -u root -p zwscloud > backup.sql

6. Enable HTTPS (if not auto-configured)
   └─ Use Let's Encrypt: certbot
   └─ Update nginx/Apache configuration

7. Monitor Application
   └─ Watch logs: tail -f ~/.pm2/logs/app-error.log
   └─ Check health: curl http://localhost:3000/health

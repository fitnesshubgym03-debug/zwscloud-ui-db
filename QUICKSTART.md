# 🚀 ZWS Cloud - 30-Second Quick Start

## The Fastest Way to Get ZWS Cloud Running

### One-Command Installation

Copy and paste this one line into your terminal:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/fitnesshubgym03-debug/zwscloud-ui-db/main/installer.sh)
```

That's it! The installer will:
- Auto-detect your operating system
- Install Node.js and PostgreSQL
- Clone the repository
- Ask if you want to use a domain or IP address
- Generate all credentials automatically
- Build the application
- Show you the login information

### What You'll Get

After ~15 minutes, you'll see:

```
✅ Installation Complete!

🌐 Application URL:    http://yourdomain.com (or your IP)
🔐 Admin Email:        admin@zwscloud.local
🔐 Admin Password:     [random password shown]

👉 Next: Open your browser and login!
```

### Start Using ZWS Cloud

1. Open your browser and go to the application URL
2. Login with the credentials shown
3. Change your admin password
4. Start using the application!

### That's All!

- No manual configuration needed
- No error handling required
- Fully automatic
- Works on: Ubuntu, Debian, CentOS, RHEL, Fedora, macOS

   • Password (minimum 8 characters)
   • Display name (optional)

2. PAYMENT GATEWAY
   • Choose Razorpay (recommended) or Cashfree
   • Enter API credentials (get from dashboard)

3. DOMAIN CONFIGURATION
   • Enter domain name OR use server IP
   • SSL certificate auto-generated if domain provided

4. DATABASE
   • Choose PostgreSQL (recommended) or MySQL
   • Enter connection details
   • Or use provided default local database

5. VERIFICATION & BUILD
   • Installer verifies everything works
   • Builds the application
   • Creates startup script

🆘 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Admin login not working?
  → Run: pnpm seed:admin
  → Check DATABASE_URL in .env.local
  → Verify admin user exists in database

Database connection error?
  → Verify database is running
  → Check connection string format
  → Ensure user has permissions

Port already in use?
  → Use: PORT=3001 ./start.sh
  → Or kill process: lsof -ti:3000 | xargs kill -9

SSL certificate error?
  → Run: sudo certbot renew
  → Check certificate: sudo certbot certificates
  → Force renewal: sudo certbot certonly --force-renewal

Payment not working?
  → Verify API credentials in .env.local
  → Check payment mode (test vs live)
  → Enable webhooks in payment dashboard
